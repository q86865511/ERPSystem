導覽互動規格(修復 ERP-001 後)提案

  1. 點擊文字/圖示區 → navigate(item.to) 導航至模組(預設分頁),同時展開子選單。父項不再用 component={Link} + 受控 opened 的組合。
  2. 點擊右側 chevron(獨立 hit-area 26×26)→ 只展開/收合,不導航。chevron 旋轉 90° 表示展開。
  3. Active 樣式:左側 3px 品牌色 rail + 淺藍底;目前子項前加圓點。
  4. 子項縮排 46px 對齊父項文字,收合動畫 150ms。
  5. 鍵盤:Enter = 導航、→/← = 展開/收合(庫存項展示 focus ring)。
  6. 行動版:點文字導航並關閉抽屜;點 chevron 展開不關抽屜。
